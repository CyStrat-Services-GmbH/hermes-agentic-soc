# Brand assets

These original company marks identify the three named contributors in the repository documentation. They do not imply that every contributor has delivered every component, and they are not covered by a proposed future code license.

| Company | Original asset | Origin | Documentation treatment |
|---|---|---|---|
| CyStrat Services GmbH | `cystrat-original.png` | [Official logo](https://www.cystrat-services.com/logo.png) | Centered on a dark panel at its native 302×87 pixel size |
| Nextron Systems | `nextron-original.svg` | [Official logo](https://www.nextron-systems.com/wp-content/uploads/2023/10/nextron-logo-text.svg) | Rasterized proportionally on a dark panel |
| exploit labs | `exploit-labs-original.svg` | [Official logo](https://xplt.com/__l5e/assets-v1/b293595b-af68-4173-b003-5d895d980da2/exploit-labs-horizontal.svg) | Rasterized proportionally on a dark panel |

The `cystrat.png`, `nextron.png` and `exploit-labs.png` documentation panels have consistent 520×180 pixel canvases, using the CyStrat dark background `#020204`. The marks are not redrawn, recolored or stretched; fixed dark panels preserve legibility in GitHub light and dark themes.

## Status badges

The six SVG files under `../badges/` are original, text-only documentation badges, not company marks. They use the CyStrat palette and are stored locally; no third-party badge image service is embedded.

Badges are static labels, not live monitors. Update version and compatibility labels with the manifest, and never change the integration or license labels to imply delivery or approval that has not occurred.
